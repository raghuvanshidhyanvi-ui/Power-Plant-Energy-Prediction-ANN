# Deep Learning Projects Using Artificial Neural Networks (ANN)

This repository contains two Deep Learning projects developed using Artificial Neural Networks (ANNs). The projects demonstrate the application of deep learning techniques to two different problems: regression and classification.

## 📌 Projects Overview

### 1. Power Plant Energy Prediction Using ANN

- **Domain:** Deep Learning
- **Problem Type:** Regression
- **Notebook:** [`ANN_Regression.ipynb`](./ANN_Regression.ipynb)
- **Dataset:** [`powerplant_data.csv`](./powerplant_data.csv)
- **Saved Model:** [`best_model.pt`](./best_model.pt)

**Objective:** Predict electrical energy output from power plant operational measurements using an Artificial Neural Network.

**Technologies:** Python, PyTorch, NumPy, Pandas, Scikit-learn, Matplotlib, and Jupyter Notebook.

### 2. Date Fruit Classification Using ANN

- **Domain:** Deep Learning
- **Problem Type:** Classification
- **Notebook:** [`ANN_Classification.ipynb`](./ANN_Classification.ipynb)
- **Dataset:** [`DateFruit_Dataset.csv`](./DateFruit_Dataset.csv)

**Objective:** Classify date fruit samples into their respective categories using an Artificial Neural Network trained on the dataset's features.

**Technologies:** Python, Jupyter Notebook, NumPy, Pandas, Scikit-learn, and the neural network framework used in the notebook.

## 🚀 Getting Started

### Prerequisites

- Python 3.x
- Jupyter Notebook
- Git

### Clone the Repository

```bash
git clone https://github.com/raghuvanshidhyanvi-ui/ann.git
cd ann
```

### Install Dependencies

For the regression project:

```bash
pip install numpy pandas scikit-learn matplotlib torch jupyter
```

Install any additional libraries required by the classification notebook.

### Run the Projects

```bash
jupyter notebook
```

Open `ANN_Regression.ipynb` or `ANN_Classification.ipynb` and execute the notebook cells in order. Ensure the corresponding dataset is available in the project directory.
